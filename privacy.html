Privacy Policy

Last updated October 13, 2026

lrod-analytics is a personal tool used only by its owner to read analytics for the owner's own YouTube, Instagram, and TikTok accounts. It has no other users.

What it accesses

It accesses only my own accounts, through each platform's official API, with read-only permissions I granted to myself. It reads my own videos' and posts' public data (such as titles, captions, publish dates, and durations) and aggregate metrics (such as views, likes, comments, shares, and watch time). It does not access anyone else's account, private messages, or personal information about viewers.

How the data is stored

The data is stored privately on my own computer. Access credentials are kept in files readable only by my user account. Nothing is published, and there is no public website or database behind this tool other than these pages.

Sharing

The data is never shared, sold, rented, or used for advertising, and it is not transferred to any third party.

Google API services

lrod-analytics's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and removal

Data is kept until I delete it. Access can be revoked at any time from each platform's connected-apps settings, after which the tool can no longer read anything.

Cookies and tracking

These pages set no cookies and use no analytics, tracking, or third-party scripts.
